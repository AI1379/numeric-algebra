# 第八章 多元函数微分学 教案

## 1 多元函数的极限与连续性

### 1.1 多元函数的概念

#### 核心概念

**定义** 设 $D$ 是 $\mathbb{R}^n$ 的一个非空子集，若对于 $D$ 中每一点 $P(x_1, x_2, \cdots, x_n)$，按照某一确定的对应法则 $f$，都有唯一确定的实数 $y$ 与之对应，则称 $f$ 为定义在 $D$ 上的 **$n$ 元函数**，记作
$$y = f(x_1, x_2, \cdots, x_n) \quad \text{或} \quad y = f(P)$$

其中 $D$ 称为函数的**定义域**，全体函数值的集合称为**值域**。

**重点理解**：

- 二元函数 $z = f(x, y)$ 的定义域是平面上的点集
- 三元函数 $u = f(x, y, z)$ 的定义域是空间中的点集
- 几何意义：二元函数的图像是三维空间中的曲面

#### 例题

**例1** 求函数 $z = \ln(x^2 + y^2 - 1)$ 的定义域。

**解**：由对数函数的定义，需要 $x^2 + y^2 - 1 > 0$，即 $x^2 + y^2 > 1$。

定义域是单位圆外部的所有点：$D = \{(x,y) \mid x^2 + y^2 > 1\}$

**例2** 求函数 $z = \sqrt{4-x^2-y^2} + \frac{1}{\sqrt{x^2+y^2-1}}$ 的定义域。

**解**：需要同时满足：

- $4 - x^2 - y^2 \geq 0$（即 $x^2 + y^2 \leq 4$）
- $x^2 + y^2 - 1 > 0$（即 $x^2 + y^2 > 1$）

定义域：$D = \{(x,y) \mid 1 < x^2 + y^2 \leq 4\}$，是圆环区域。

### 1.2 平面点集

#### 核心概念

**邻域** 设 $P_0(x_0, y_0)$ 是平面上一点，$\delta > 0$，则称点集
$$U(P_0, \delta) = \{(x,y) \mid \sqrt{(x-x_0)^2 + (y-y_0)^2} < \delta\}$$
为点 $P_0$ 的**$\delta$-邻域**。

**去心邻域**：$\mathring{U}(P_0, \delta) = \{(x,y) \mid 0 < \sqrt{(x-x_0)^2 + (y-y_0)^2} < \delta\}$

**点的分类**：

| 类型 | 内点 | 外点 | 边界点 |
|------|------|------|--------|
| 定义 | 存在完全属于 $E$ 的邻域 | 存在完全不属于 $E$ 的邻域 | 任意邻域都与 $E$ 及 $E^c$ 都相交 |

**区域的分类**：

- **开集**：每一点都是内点的集合
- **闭集**：开集的补集
- **连通集**：集合中任意两点可用完全属于该集合的折线连接
- **区域（开区域）**：连通的开集
- **闭区域**：区域连同其边界

### 1.3 二元函数的极限与连续

#### 一、二元函数的极限

**定义** 设函数 $f(x,y)$ 在点 $P_0(x_0, y_0)$ 的某去心邻域内有定义。若存在常数 $A$，对于任意给定的 $\varepsilon > 0$，总存在 $\delta > 0$，使得当
$$0 < \sqrt{(x-x_0)^2 + (y-y_0)^2} < \delta$$
时，恒有 $|f(x,y) - A| < \varepsilon$，则称 $A$ 为函数 $f(x,y)$ 当 $(x,y) \to (x_0, y_0)$ 时的**极限**，记作
$$\lim_{(x,y) \to (x_0,y_0)} f(x,y) = A$$

**易错点**：

1. 极限要求点 $(x,y)$ 以**任何方式、任何路径**趋于 $(x_0, y_0)$ 时，$f(x,y)$ 都趋于同一个值 $A$
2. 如果沿不同路径极限值不同，则极限不存在

#### 证明极限的核心方法

**方法1：用定义证明极限**

核心步骤是用不等式放缩，找到 $\delta$ 与 $\varepsilon$ 的关系。

**例3** 用定义证明 $\lim_{(x,y) \to (0,0)} \frac{x^2y}{x^2+y^2} = 0$。

**证明**：设 $r = \sqrt{x^2+y^2}$，则 $|x| \leq r$，$|y| \leq r$。

$$\left|\frac{x^2y}{x^2+y^2} - 0\right| = \frac{|x^2y|}{x^2+y^2} \leq \frac{|x|^2|y|}{x^2} = |y| \leq r$$

对于任意 $\varepsilon > 0$，取 $\delta = \varepsilon$，当 $0 < r < \delta$ 时，有 $|f(x,y)| < \varepsilon$。

**方法2：证明极限不存在**

找两条不同路径，使得极限值不同。

**例4** 证明 $\lim_{(x,y) \to (0,0)} \frac{xy}{x^2+y^2}$ 不存在。

**证明**：沿不同路径考察：

- 沿 $y = 0$（$x$ 轴）：$\lim_{x \to 0} \frac{x \cdot 0}{x^2 + 0} = 0$
- 沿 $y = x$：$\lim_{x \to 0} \frac{x \cdot x}{x^2 + x^2} = \lim_{x \to 0} \frac{x^2}{2x^2} = \frac{1}{2}$

两个极限值不同，故原极限不存在。

**例5** 证明 $\lim_{(x,y) \to (0,0)} \frac{x^2y}{x^4+y^2}$ 不存在。

**证明**：

- 沿 $y = 0$：极限为 $0$
- 沿 $y = x^2$：$\lim_{x \to 0} \frac{x^2 \cdot x^2}{x^4 + x^4} = \lim_{x \to 0} \frac{x^4}{2x^4} = \frac{1}{2}$

极限不存在。

**特别提醒**：沿所有直线方向极限相同，不一定能保证极限存在。必须用定义或其他方法来判断。

#### 二、累次极限与重极限

**累次极限**：
$$\lim_{x \to x_0}\lim_{y \to y_0} f(x,y) \quad \text{或} \quad \lim_{y \to y_0}\lim_{x \to x_0} f(x,y)$$

**重极限**：$\lim_{(x,y) \to (x_0,y_0)} f(x,y)$

**关系**：

- 重极限存在，且累次极限存在时，它们相等
- 两个累次极限存在且相等，**不能保证**重极限存在
- 重极限存在，**不能保证**累次极限存在

#### 三、二元函数的连续性

**定义** 设函数 $f(x,y)$ 在点 $P_0(x_0, y_0)$ 的某邻域内有定义，若
$$\lim_{(x,y) \to (x_0,y_0)} f(x,y) = f(x_0, y_0)$$
则称函数 $f(x,y)$ 在点 $P_0$ **连续**。

**连续函数的性质**：

1. 有限个连续函数的和、差、积、商（分母不为零）仍连续
2. 连续函数的复合函数仍连续
3. 二元初等函数在其定义域内连续

**闭区域上连续函数的性质**：

| 性质 | 内容 |
|------|------|
| 有界性定理 | 在有界闭区域 $D$ 上连续，则 $f$ 在 $D$ 上有界 |
| 最大最小值定理 | 在有界闭区域 $D$ 上连续，则 $f$ 在 $D$ 上取得最大值和最小值 |
| 介值定理 | 若 $f$ 在有界闭区域 $D$ 上连续，$m$ 和 $M$ 为最小值和最大值，则对任意 $m \leq \mu \leq M$，存在点使 $f(P) = \mu$ |

## 2 偏导数与全微分

### 2.1 偏导数

#### 核心概念

**偏导数的定义** 设函数 $z = f(x, y)$ 在点 $(x_0, y_0)$ 的某邻域内有定义，若极限
$$\lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$
存在，则称此极限为函数 $f(x, y)$ 在点 $(x_0, y_0)$ 处**对 $x$ 的偏导数**，记作
$$\frac{\partial z}{\partial x}\bigg|_{\substack{x=x_0 \\ y=y_0}} \quad \text{或} \quad f_x(x_0, y_0) \quad \text{或} \quad z_x(x_0, y_0)$$

类似地定义对 $y$ 的偏导数。

**计算方法**：对哪个变量求偏导，就把其他变量视为常数，用一元函数的求导法则。

#### 高阶偏导数

**定义** 偏导数的偏导数称为二阶偏导数，记作：

- $\frac{\partial^2 z}{\partial x^2} = f_{xx}(x, y)$
- $\frac{\partial^2 z}{\partial y^2} = f_{yy}(x, y)$
- $\frac{\partial^2 z}{\partial x \partial y} = f_{xy}(x, y)$（先对 $x$ 再对 $y$）
- $\frac{\partial^2 z}{\partial y \partial x} = f_{yx}(x, y)$（先对 $y$ 再对 $x$）

后两个称为**混合偏导数**。

**重要定理：混合偏导数相等的条件**

若 $f_{xy}(x, y)$ 和 $f_{yx}(x, y)$ 在点 $(x_0, y_0)$ 处连续，则
$$f_{xy}(x_0, y_0) = f_{yx}(x_0, y_0)$$

**证明核心**：利用二重极限交换次序的思想，考虑累次差分：
$$F = f(x_0 + h, y_0 + k) - f(x_0 + h, y_0) - f(x_0, y_0 + k) + f(x_0, y_0)$$

用两种方式展开（先对 $k$ 或先对 $h$），再利用连续性取极限。

#### 例题

**例6** 设 $z = x^y + e^{xy} \sin(x+y)$，求 $\frac{\partial z}{\partial x}$ 和 $\frac{\partial z}{\partial y}$。

**解**：
$$\frac{\partial z}{\partial x} = yx^{y-1} + ye^{xy}\sin(x+y) + e^{xy}\cos(x+y)$$
$$\frac{\partial z}{\partial y} = x^y \ln x + xe^{xy}\sin(x+y) + e^{xy}\cos(x+y)$$

**例7** 设 $z = \arctan\frac{y}{x}$，求 $z_{xx} + z_{yy}$。

**解**：

先求一阶偏导：
$$z_x = \frac{1}{1+(\frac{y}{x})^2} \cdot (-\frac{y}{x^2}) = \frac{-y}{x^2+y^2}$$
$$z_y = \frac{1}{1+(\frac{y}{x})^2} \cdot \frac{1}{x} = \frac{x}{x^2+y^2}$$

再求二阶偏导：
$$z_{xx} = \frac{\partial}{\partial x}\left(\frac{-y}{x^2+y^2}\right) = \frac{2xy}{(x^2+y^2)^2}$$
$$z_{yy} = \frac{\partial}{\partial y}\left(\frac{x}{x^2+y^2}\right) = \frac{-2xy}{(x^2+y^2)^2}$$

所以 $z_{xx} + z_{yy} = 0$。

**易错点**：

1. 求偏导时要明确对哪个变量求导，其他变量视为常数
2. 注意 $x^y$ 类型函数的偏导：对 $x$ 用幂函数法则，对 $y$ 用指数函数法则
3. 混合偏导数相等需要连续条件

### 2.2 全微分

#### 核心概念

**定义** 设函数 $z = f(x, y)$ 在点 $(x_0, y_0)$ 的某邻域内有定义，若存在常数 $A$、$B$，使得
$$\Delta z = f(x_0 + \Delta x, y_0 + \Delta y) - f(x_0, y_0) = A\Delta x + B\Delta y + o(\rho)$$
其中 $\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$，则称函数 $f$ 在点 $(x_0, y_0)$ **可微**，线性主部 $A\Delta x + B\Delta y$ 称为 $f$ 在该点的**全微分**，记作
$$dz = A\Delta x + B\Delta y = A\,dx + B\,dy$$

**重要定理**：若 $f$ 可微，则
$$A = \frac{\partial f}{\partial x} \Big|_{(x_0, y_0)}, \quad B = \frac{\partial f}{\partial y} \Big|_{(x_0, y_0)}$$

即 $dz = \frac{\partial f}{\partial x}dx + \frac{\partial f}{\partial y}dy$。

#### 可微的条件

| 类型 | 条件 | 结论 |
|------|------|------|
| 必要条件 | $f$ 可微 | 偏导数存在 |
| 充分条件 | 偏导数连续 | $f$ 可微 |
| 充要条件 | 用定义验证 | $\lim_{(\Delta x, \Delta y) \to (0,0)} \frac{\Delta z - f_x\Delta x - f_y\Delta y}{\sqrt{(\Delta x)^2 + (\Delta y)^2}} = 0$ |

**易错点**：

1. 偏导数存在 **推不出** 可微
2. 可微 **推不出** 偏导数连续

**例8** 证明函数 $f(x,y) = \sqrt{|xy|}$ 在原点偏导数存在，但不可微。

**证明**：
（1）由定义，$f_x(0,0) = \lim_{\Delta x \to 0} \frac{f(\Delta x, 0) - f(0,0)}{\Delta x} = \lim_{\Delta x \to 0} \frac{0}{\Delta x} = 0$

同理 $f_y(0,0) = 0$。

（2）若可微，应有 $\Delta z = f_x \cdot \Delta x + f_y \cdot \Delta y + o(\rho) = o(\rho)$

取 $\Delta x = \Delta y = t \to 0$，$\rho = \sqrt{2}|t|$
$$\Delta z = |t|, \quad \lim_{t \to 0} \frac{|t|}{\sqrt{2}|t|} = \frac{1}{\sqrt{2}} \neq 0$$

矛盾，故不可微。

#### 全微分的形式不变性

设 $z = f(u, v)$，$u = u(x, y)$，$v = v(x, y)$，无论 $u$、$v$ 是自变量还是中间变量，都有
$$dz = \frac{\partial f}{\partial u}du + \frac{\partial f}{\partial v}dv = \frac{\partial z}{\partial x}dx + \frac{\partial z}{\partial y}dy$$

#### 应用：近似计算

当 $|\Delta x|$，$|\Delta y|$ 很小时：
$$f(x_0 + \Delta x, y_0 + \Delta y) \approx f(x_0, y_0) + f_x(x_0, y_0)\Delta x + f_y(x_0, y_0)\Delta y$$

**例9** 计算 $(1.02)^{3.01}$ 的近似值。

**解**：设 $f(x, y) = x^y$，取 $x_0 = 1$，$y_0 = 3$，$\Delta x = 0.02$，$\Delta y = 0.01$。

$f_x = yx^{y-1}$，$f_y = x^y \ln x$

$f(1, 3) = 1$，$f_x(1, 3) = 3$，$f_y(1, 3) = 0$

$(1.02)^{3.01} \approx 1 + 3 \times 0.02 + 0 \times 0.01 = 1.06$

## 3 复合函数微分法

### 3.1 复合函数的偏导数

#### 链式法则

**情况一：一个中间变量**

设 $z = f(u)$，$u = u(x, y)$，则
$$\frac{\partial z}{\partial x} = \frac{df}{du} \cdot \frac{\partial u}{\partial x}$$

**情况二：两个中间变量（核心）**

设 $z = f(u, v)$，$u = u(x, y)$，$v = v(x, y)$，若各函数都可微，则
$$\frac{\partial z}{\partial x} = \frac{\partial f}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial f}{\partial v}\frac{\partial v}{\partial x}$$
$$\frac{\partial z}{\partial y} = \frac{\partial f}{\partial u}\frac{\partial u}{\partial y} + \frac{\partial f}{\partial v}\frac{\partial v}{\partial y}$$

**情况三：全导数（一个自变量）**

设 $z = f(u, v)$，$u = u(t)$，$v = v(t)$，则
$$\frac{dz}{dt} = \frac{\partial f}{\partial u}\frac{du}{dt} + \frac{\partial f}{\partial v}\frac{dv}{dt}$$

#### 易错点：记号区分

- $\frac{\partial z}{\partial x}$：$z$ 对自变量 $x$ 的偏导（考虑所有依赖关系）
- $\frac{\partial f}{\partial u}$：$f$ 对中间变量 $u$ 直接求偏导（其他中间变量视为常数）

当 $z = f(x, y, u)$，而 $u = u(x, y)$ 时：

- $\frac{\partial z}{\partial x} = \frac{\partial f}{\partial x} + \frac{\partial f}{\partial u}\frac{\partial u}{\partial x}$
- 这里 $\frac{\partial z}{\partial x} \neq \frac{\partial f}{\partial x}$

#### 例题

**例10** 设 $z = e^{u-2v}$，$u = \sin x$，$v = x^3$，求 $\frac{dz}{dx}$。

**解**：
$$\frac{dz}{dx} = \frac{\partial z}{\partial u}\frac{du}{dx} + \frac{\partial z}{\partial v}\frac{dv}{dx} = e^{u-2v} \cdot \cos x + (-2)e^{u-2v} \cdot 3x^2$$

代入 $u = \sin x$，$v = x^3$：
$$= e^{\sin x - 2x^3}(\cos x - 6x^2)$$

**例11** 设 $z = f(x^2 - y^2, e^{xy})$，$f$ 有二阶连续偏导数，求 $\frac{\partial z}{\partial x}$ 和 $\frac{\partial^2 z}{\partial x \partial y}$。

**解**：设 $u = x^2 - y^2$，$v = e^{xy}$，则 $z = f(u, v)$。

$$\frac{\partial z}{\partial x} = f_1 \cdot 2x + f_2 \cdot ye^{xy}$$

其中 $f_1 = \frac{\partial f}{\partial u}$，$f_2 = \frac{\partial f}{\partial v}$。

$$\frac{\partial^2 z}{\partial x \partial y} = \frac{\partial}{\partial y}(2xf_1 + ye^{xy}f_2)$$

$= 2x(f_{11} \cdot (-2y) + f_{12} \cdot xe^{xy}) + e^{xy}f_2 + ye^{xy}f_2 + ye^{xy}(f_{21} \cdot (-2y) + f_{22} \cdot xe^{xy})$

利用 $f_{12} = f_{21}$：
$$= -4xy f_{11} + (2x^2 - 2y^2)e^{xy}f_{12} + e^{xy}f_2 + xy e^{2xy}f_{22} + ye^{xy}f_2$$

### 3.2 复合函数的全微分

设 $z = f(u, v)$，$u = u(x, y)$，$v = v(x, y)$ 均可微，则

$$dz = \frac{\partial z}{\partial x}dx + \frac{\partial z}{\partial y}dy$$

利用形式不变性，也可写成
$$dz = \frac{\partial f}{\partial u}du + \frac{\partial f}{\partial v}dv$$

## 4 隐函数的偏导数

### 4.1 隐函数的偏导数

#### 一个方程的情形

**隐函数存在定理** 设函数 $F(x, y)$ 在点 $P_0(x_0, y_0)$ 的某邻域内有连续偏导数，且 $F(x_0, y_0) = 0$，$F_y(x_0, y_0) \neq 0$，则方程 $F(x, y) = 0$ 在点 $P_0$ 的某邻域内唯一确定一个连续可导的隐函数 $y = y(x)$，使得：

- $y_0 = y(x_0)$
- $\frac{dy}{dx} = -\frac{F_x}{F_y}$

**公式**：$\frac{dy}{dx} = -\frac{F_x}{F_y}$

**推广到多元**：若 $F(x, y, z) = 0$ 确定 $z = z(x, y)$，则
$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$$

#### 例题

**例12** 设 $x^2 + y^2 + z^2 - 4z = 0$，求 $\frac{\partial z}{\partial x}$ 和 $\frac{\partial^2 z}{\partial x^2}$。

**解**：设 $F(x, y, z) = x^2 + y^2 + z^2 - 4z$

$F_x = 2x$，$F_z = 2z - 4$

$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z} = -\frac{2x}{2z-4} = \frac{x}{2-z}$$

$$\frac{\partial^2 z}{\partial x^2} = \frac{\partial}{\partial x}\left(\frac{x}{2-z}\right) = \frac{(2-z) + x \cdot \frac{\partial z}{\partial x}}{(2-z)^2} = \frac{2-z + \frac{x^2}{2-z}}{(2-z)^2} = \frac{(2-z)^2 + x^2}{(2-z)^3}$$

### 4.2 隐函数组的偏导数

#### 方程组情形

设方程组
$$\begin{cases} F(x, y, u, v) = 0 \\ G(x, y, u, v) = 0 \end{cases}$$

在满足一定条件下确定隐函数组 $u = u(x, y)$，$v = v(x, y)$。

**雅可比行列式**：
$$J = \frac{\partial(F, G)}{\partial(u, v)} = \begin{vmatrix} F_u & F_v \\ G_u & G_v \end{vmatrix}$$

**公式**：
$$\frac{\partial u}{\partial x} = -\frac{1}{J}\frac{\partial(F, G)}{\partial(x, v)} = -\frac{1}{J}\begin{vmatrix} F_x & F_v \\ G_x & G_v \end{vmatrix}$$

$$\frac{\partial v}{\partial x} = -\frac{1}{J}\frac{\partial(F, G)}{\partial(u, x)} = -\frac{1}{J}\begin{vmatrix} F_u & F_x \\ G_u & G_x \end{vmatrix}$$

**例13** 设 $\begin{cases} x = u + v \\ y = u^2 + v^2 \end{cases}$，求 $\frac{\partial u}{\partial x}$ 和 $\frac{\partial v}{\partial x}$。

**解**：改写成 $F = u + v - x = 0$，$G = u^2 + v^2 - y = 0$。

$$J = \begin{vmatrix} 1 & 1 \\ 2u & 2v \end{vmatrix} = 2v - 2u \neq 0 \text{（当 } u \neq v \text{）}$$

$$\frac{\partial u}{\partial x} = -\frac{1}{J}\begin{vmatrix} -1 & 1 \\ 0 & 2v \end{vmatrix} = -\frac{1}{2(v-u)}(-2v) = \frac{v}{v-u}$$

$$\frac{\partial v}{\partial x} = -\frac{1}{J}\begin{vmatrix} 1 & -1 \\ 2u & 0 \end{vmatrix} = -\frac{1}{2(v-u)}(2u) = \frac{u}{u-v}$$

## 5 场的方向导数与梯度

### 5.1 场的概念

**定义**

- **数量场**：空间区域中每点对应一个数量值，如温度场、密度场
- **向量场**：空间区域中每点对应一个向量，如流速场、电场

### 5.2 场的方向导数

#### 定义

设函数 $z = f(x, y)$ 在点 $P_0(x_0, y_0)$ 的某邻域内有定义，$\vec{l}$ 是从 $P_0$ 出发的方向向量，$\vec{e}_l = (\cos\alpha, \cos\beta)$ 是单位方向向量。若极限
$$\lim_{t \to 0^+} \frac{f(x_0 + t\cos\alpha, y_0 + t\cos\beta) - f(x_0, y_0)}{t}$$
存在，则称此极限为 $f$ 在点 $P_0$ 沿方向 $\vec{l}$ 的**方向导数**，记作 $\frac{\partial f}{\partial l}\big|_{P_0}$。

#### 计算公式

若 $f(x,y)$ 在点 $P_0$ 可微，则方向导数存在且
$$\frac{\partial f}{\partial l} = \frac{\partial f}{\partial x}\cos\alpha + \frac{\partial f}{\partial y}\cos\beta$$

**推广到三元函数**：
$$\frac{\partial f}{\partial l} = \frac{\partial f}{\partial x}\cos\alpha + \frac{\partial f}{\partial y}\cos\beta + \frac{\partial f}{\partial z}\cos\gamma$$

#### 例题

**例14** 求 $f(x, y, z) = x^2 + 2y^2 + 3z^2$ 在点 $(1, 1, 1)$ 沿方向 $\vec{l} = (1, 2, 2)$ 的方向导数。

**解**：单位化 $\vec{e}_l = (\frac{1}{3}, \frac{2}{3}, \frac{2}{3})$

$\frac{\partial f}{\partial x} = 2x$，$\frac{\partial f}{\partial y} = 4y$，$\frac{\partial f}{\partial z} = 6z$

在点 $(1, 1, 1)$：$f_x = 2$，$f_y = 4$，$f_z = 6$

$$\frac{\partial f}{\partial l} = 2 \cdot \frac{1}{3} + 4 \cdot \frac{2}{3} + 6 \cdot \frac{2}{3} = \frac{2 + 8 + 12}{3} = \frac{22}{3}$$

---

### 5.3 梯度

#### 定义

设函数 $f(x, y)$ 在点 $P_0$ 可微，向量
$$\nabla f = \frac{\partial f}{\partial x}\vec{i} + \frac{\partial f}{\partial y}\vec{j} = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}\right)$$
称为 $f$ 在点 $P_0$ 的**梯度**，记作 $\text{grad } f$ 或 $\nabla f$（读作 "nabla f" 或 "del f"）。

#### 梯度与方向导数的关系

$$\frac{\partial f}{\partial l} = \nabla f \cdot \vec{e}_l = |\nabla f| \cos\theta$$

其中 $\theta$ 是梯度方向与 $\vec{l}$ 方向的夹角。

**重要结论**：

- 当 $\vec{l}$ 与梯度同方向时，方向导数最大，最大值 $|\nabla f|$
- 梯度方向是函数增长最快的方向
- 梯度的模是函数在该点的最大变化率

#### 梯度的几何意义

梯度方向垂直于等值线（等值面），指向函数值增大的方向。

**例15** 求函数 $f(x, y) = x^2 + y^2$ 在点 $(1, 2)$ 处的梯度，并求梯度方向的单位向量。

**解**：
$\nabla f = (2x, 2y)$

在点 $(1, 2)$ 处：$\nabla f = (2, 4)$

$|\nabla f| = \sqrt{4 + 16} = 2\sqrt{5}$

梯度方向的单位向量：$\vec{e} = \frac{1}{2\sqrt{5}}(2, 4) = \frac{1}{\sqrt{5}}(1, 2)$

## 6 多元函数的极值及应用

### 6.1 多元函数的泰勒公式

#### 二元函数的泰勒公式

设函数 $f(x, y)$ 在点 $(x_0, y_0)$ 的某邻域内有直到 $n+1$ 阶连续偏导数，则

$$f(x, y) = f(x_0, y_0) + \sum_{k=1}^{n}\frac{1}{k!}\left[(x-x_0)\frac{\partial}{\partial x} + (y-y_0)\frac{\partial}{\partial y}\right]^k f(x_0, y_0) + R_n$$

其中 $R_n$ 为余项。

**二阶泰勒展开**（常用）：
$$f(x,y) \approx f(x_0,y_0) + f_x \Delta x + f_y \Delta y + \frac{1}{2}(f_{xx}\Delta x^2 + 2f_{xy}\Delta x \Delta y + f_{yy}\Delta y^2)$$

---

### 6.2 多元函数的极值

#### 无条件极值

**定义** 若在点 $P_0$ 的某邻域内，恒有 $f(P) \leq f(P_0)$（或 $f(P) \geq f(P_0)$），则称 $f$ 在 $P_0$ 取得极大（小）值。

**必要条件** 若 $f$ 在 $P_0$ 有极值且偏导数存在，则
$$f_x(P_0) = 0, \quad f_y(P_0) = 0$$

满足上述条件的点称为**驻点**。

**易错点**：驻点不一定是极值点。

**充分条件** 设 $f$ 在点 $P_0$ 有二阶连续偏导数，$P_0$ 是驻点，记
$$A = f_{xx}(P_0), \quad B = f_{xy}(P_0), \quad C = f_{yy}(P_0), \quad \Delta = AC - B^2$$

| $\Delta$ 的符号 | 结论 |
|----------------|------|
| $\Delta > 0$ 且 $A < 0$ | 极大值 |
| $\Delta > 0$ 且 $A > 0$ | 极小值 |
| $\Delta < 0$ | 不是极值（鞍点） |
| $\Delta = 0$ | 方法失效，需用其他方法 |

**证明核心**：利用泰勒展开，在驻点处的二阶项主导函数值变化。

#### 例题

**例16** 求函数 $f(x, y) = x^3 + y^3 - 3xy$ 的极值。

**解**：
求驻点：$\begin{cases} f_x = 3x^2 - 3y = 0 \\ f_y = 3y^2 - 3x = 0 \end{cases}$

解得驻点：$(0, 0)$ 和 $(1, 1)$

二阶偏导：$f_{xx} = 6x$，$f_{xy} = -3$，$f_{yy} = 6y$

在 $(0, 0)$：$A = 0$，$B = -3$，$C = 0$，$\Delta = 0 - 9 = -9 < 0$

不是极值点，是鞍点。

在 $(1, 1)$：$A = 6$，$B = -3$，$C = 6$，$\Delta = 36 - 9 = 27 > 0$，$A > 0$

故 $(1, 1)$ 是极小值点，极小值 $f(1, 1) = -1$。

---

#### 条件极值与拉格朗日乘数法

**问题**：在条件 $\varphi(x, y, z) = 0$ 下，求 $f(x, y, z)$ 的极值。

**拉格朗日乘数法**：

构造拉格朗日函数
$$L(x, y, z, \lambda) = f(x, y, z) + \lambda \varphi(x, y, z)$$

解方程组：
$$\begin{cases} L_x = f_x + \lambda\varphi_x = 0 \\ L_y = f_y + \lambda\varphi_y = 0 \\ L_z = f_z + \lambda\varphi_z = 0 \\ \varphi(x, y, z) = 0 \end{cases}$$

**多个约束条件**：$\varphi_1 = 0, \varphi_2 = 0, \cdots$

$$L(x, y, z, \lambda_1, \lambda_2) = f + \lambda_1\varphi_1 + \lambda_2\varphi_2$$

#### 例题

**例17** 求椭球面 $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ 内接长方体的最大体积。

**解**：设内接长方体在第一卦限的顶点为 $(x, y, z)$，则体积 $V = 8xyz$。

约束条件：$\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$

构造拉格朗日函数：
$$L = 8xyz + \lambda\left(\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} - 1\right)$$

解方程组：
$$\begin{cases} 8yz + \lambda \cdot \frac{2x}{a^2} = 0 \\ 8xz + \lambda \cdot \frac{2y}{b^2} = 0 \\ 8xy + \lambda \cdot \frac{2z}{c^2} = 0 \\ \frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1 \end{cases}$$

由前三个方程得：$\frac{2x^2}{a^2} = \frac{2y^2}{b^2} = \frac{2z^2}{c^2} = -\frac{8xyz}{\lambda}$

代入约束条件，得 $\frac{3x^2}{a^2} = 1$，即 $x = \frac{a}{\sqrt{3}}$，同理 $y = \frac{b}{\sqrt{3}}$，$z = \frac{c}{\sqrt{3}}$

最大体积 $V_{max} = 8 \cdot \frac{a}{\sqrt{3}} \cdot \frac{b}{\sqrt{3}} \cdot \frac{c}{\sqrt{3}} = \frac{8abc}{3\sqrt{3}}$

---

#### 最值问题

在有界闭区域 $D$ 上求函数的最大、最小值：

1. 求出 $D$ 内部的所有驻点和偏导数不存在的点
2. 求出 $D$ 边界上的最值点（用条件极值法）
3. 比较所有可疑点的函数值

**例18** 求 $f(x, y) = x^2 + 2y^2$ 在区域 $D = \{(x,y) \mid x^2 + y^2 \leq 1\}$ 上的最值。

**解**：
（1）内部：$f_x = 2x = 0$，$f_y = 4y = 0$，驻点 $(0, 0)$，$f(0, 0) = 0$

（2）边界：$x^2 + y^2 = 1$

设 $L = x^2 + 2y^2 + \lambda(x^2 + y^2 - 1)$

$L_x = 2x + 2\lambda x = 0$，$L_y = 4y + 2\lambda y = 0$

边界上点：

- $x = 0$：$y = \pm 1$，$f = 2$
- $y = 0$：$x = \pm 1$，$f = 1$

最大值 $f(0, \pm 1) = 2$，最小值 $f(0, 0) = 0$

## 7 偏导数在几何上的应用

### 7.1 矢值函数的微分法

#### 定义

**矢值函数** $\vec{r}(t) = (x(t), y(t), z(t))$，其中 $x(t), y(t), z(t)$ 是参数 $t$ 的函数。

**导数**：
$$\vec{r}'(t) = (x'(t), y'(t), z'(t))$$

**微分法则**：

- $(\vec{r}_1 + \vec{r}_2)' = \vec{r}_1' + \vec{r}_2'$
- $(c\vec{r})' = c\vec{r}'$
- $(\vec{r}_1 \cdot \vec{r}_2)' = \vec{r}_1' \cdot \vec{r}_2 + \vec{r}_1 \cdot \vec{r}_2'$
- $(\vec{r}_1 \times \vec{r}_2)' = \vec{r}_1' \times \vec{r}_2 + \vec{r}_1 \times \vec{r}_2'$

---

### 7.2 空间曲线的切线与法平面

#### 参数方程形式

曲线 $\vec{r}(t) = (x(t), y(t), z(t))$

**切向量**：$\vec{T} = \vec{r}'(t_0) = (x'(t_0), y'(t_0), z'(t_0))$

**切线方程**：
$$\frac{x - x_0}{x'(t_0)} = \frac{y - y_0}{y'(t_0)} = \frac{z - z_0}{z'(t_0)}$$

**法平面方程**：
$$x'(t_0)(x - x_0) + y'(t_0)(y - y_0) + z'(t_0)(z - z_0) = 0$$

#### 两曲面交线形式

曲线由 $\begin{cases} F(x, y, z) = 0 \\ G(x, y, z) = 0 \end{cases}$ 给出。

**切向量**：$\vec{T} = \nabla F \times \nabla G$（在点 $P_0$ 处）

**例19** 求曲线 $x = t$，$y = t^2$，$z = t^3$ 在点 $(1, 1, 1)$ 处的切线方程。

**解**：点 $(1, 1, 1)$ 对应 $t = 1$

$\vec{r}'(t) = (1, 2t, 3t^2)$，$\vec{r}'(1) = (1, 2, 3)$

切线方程：$\frac{x-1}{1} = \frac{y-1}{2} = \frac{z-1}{3}$

---

### 7.3 空间曲面的切平面与法线

#### 隐式方程 $F(x, y, z) = 0$

**法向量**：$\vec{n} = \nabla F = (F_x, F_y, F_z)$（在点 $P_0$ 处）

**切平面方程**：
$$F_x(P_0)(x - x_0) + F_y(P_0)(y - y_0) + F_z(P_0)(z - z_0) = 0$$

**法线方程**：
$$\frac{x - x_0}{F_x(P_0)} = \frac{y - y_0}{F_y(P_0)} = \frac{z - z_0}{F_z(P_0)}$$

#### 显式方程 $z = f(x, y)$

化为 $F(x, y, z) = f(x, y) - z = 0$

**法向量**：$\vec{n} = (f_x, f_y, -1)$

**切平面方程**：
$$z - z_0 = f_x(x_0, y_0)(x - x_0) + f_y(x_0, y_0)(y - y_0)$$

**例20** 求球面 $x^2 + y^2 + z^2 = 14$ 在点 $(1, 2, 3)$ 处的切平面方程。

**解**：设 $F = x^2 + y^2 + z^2 - 14$

$\nabla F = (2x, 2y, 2z)$，在 $(1, 2, 3)$ 处为 $(2, 4, 6)$

切平面方程：$2(x-1) + 4(y-2) + 6(z-3) = 0$

即 $x + 2y + 3z = 14$

## 本章重点总结

### 关键概念

1. 多元函数极限：任意路径趋于同一点
2. 偏导数：固定其他变量，对某变量求导
3. 全微分：线性主部，$\Delta z = dz + o(\rho)$
4. 梯度：增长最快的方向，垂直于等值线/面

### 重要定理

1. 混合偏导数相等的条件：连续
2. 可微的充分条件：偏导数连续
3. 极值判定：$\Delta = AC - B^2$ 的符号

### 计算公式

1. 链式法则
2. 隐函数求导：$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}$
3. 方向导数：$\frac{\partial f}{\partial l} = \nabla f \cdot \vec{e}_l$
4. 拉格朗日乘数法

### 易错点

1. 极限存在需要所有路径极限相同
2. 偏导存在 $\not\Rightarrow$ 可微 $\not\Rightarrow$ 偏导连续
3. 驻点不一定是极值点
4. $\frac{\partial z}{\partial x}$ 与 $\frac{\partial f}{\partial x}$ 记号区分
